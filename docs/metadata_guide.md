# Citation Metadata Guide

This guide provides the details for each parameter available to users when creating a citation, whether they are mandatory/optional, autofilled or otherwise.

## Title
- Autogenerated or optional
- If provided, will override autogeneration (contructed from facets according to project_id as described on the UI edit page.)

## Abstract
- Autogenerated or optional
- If provided, will override autogeneration (constructed using ESGVOC plus hardcoded project descriptions - you may save with no abstract, then edit autogenerated abstract if useful.)

## Data Access URL
- Optional
- Only required if the data will not be present on ESGF-NG data nodes

## DOI
- Optional
- Only provide if there is already a DOI for the data.

## DOI Publication Date
- Optional
- As above, only provide if a DOI has already been obtained.

## Search Facets
- Required
- Facets validated depending on project ID. Domain is only required for CORDEX records, in which case the experiment becomes the 'driving' experiment. All other facets are required but do not include the 'cmip7:' or 'cordex-cmip6:' etc. Case insensitive but would be best to follow how STAC facets are arranged.

## Licensing and Fair Use
- Rights/License autogenerated
- Only provide if rights are not cc-by-4.0 and license text is not the standard paragraph for CMIP7 or CORDEX-CMIP6.
- Able to autogenerate initially, then re-edit to change things if useful.

## Contacts
- Primary contact (checkbox) required
- Other contacts optional
- First and last name required for each, plus any middle names
- Contacts will always be displayed in the order they are presented in the form (UI allows rearrangement)
- **NOTE**: Contacts are not editable after creation, you will have to remove then readd the person if there are issues.
- Party objects are identified by an ID which is based on a hash of the first, last and middle names. To alter other properties (Email, ORCID) for an existing party, add their details manually, ensuring you have the correct names. This will override existing values.
- For any problems with duplicate authors please contact the CEDA helpdesk.

## Affiliated Institutions
- Name required for any institution provided. If the institution already exists in the citation service ensure you have the correct name exactly as presented. Acronym and Country are optional.
- **NOTE**: The institution ID search facet will automatically be used to add the corresponding institution to the record so you should not need to add it manually here.

## Funding Streams
- As above with requirements.
- If the affiliation matches an existing institution, the funding stream will be linked to that institution so it appears in the list of streams the institution has provided (see the Institutions view)

## References
- Title Field will be auto-matched to an existing record if the DOI already exists in the citation service. (Since there is no view for individual references this only matters if you have personally already entered a particular reference into another record)
- Title will be highlighted in bold and DOI will be hyperlinked in the rendering automatically **IF** the Cite As box contains the full citation including both title and DOI. i.e the cite as box should look exactly how the reference would appear in a paper, including title and DOI.
